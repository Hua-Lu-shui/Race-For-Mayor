# 我要当市长

欢迎来到《我要当市长》！

这是一张支持最多 8 名玩家的多人竞选地图。每位玩家都将扮演一名市长候选人，在一轮轮城市议题与实地行动中经营自己的形象和政绩，争取在最终计票中胜出，成为新任市长。

## 游戏目标

竞选表现由四项属性决定：

- **名誉**：公众形象、媒体评价与竞选声望
- **经济**：财政状况、商业活力、就业与城市发展
- **民生**：公共服务、住房、教育与生活保障
- **生态**：环境质量、污染治理与城市宜居度

游戏结束时，四项属性会按照各自的最终权重换算成选票。总票数最高的玩家将赢得选举。

> 最终得票 = 名誉 × 名誉权重 + 经济 × 经济权重 + 民生 × 民生权重 + 生态 × 生态权重

## 候选人身份

游戏开始前，每位玩家可以选择自己的候选人身份。不同身份拥有不同的初始优势：

- **明星**：擅长名誉与经济
- **企业家**：拥有最强的经济基础
- **社区领袖**：在民生方面表现突出
- **学者**：更重视生态发展
- **公务员**：四项属性较为均衡

身份只是竞选的起点。之后的每一次选择，都会改变你的发展方向。

## 每轮怎么玩

游戏开始后，玩家会进入各自的办公室。每轮任务开始时，所有人需要在 30 秒内完成选择。

### 决策任务

大多数玩家会处理一项城市议题。你需要先从随机出现的三个属性方向中选择一个，再阅读对应事件的背景，并在不同政策方案中作出决定。

方案不会提前显示具体数值变化。请根据事件背景判断它对城市可能造成的影响。

### 行动任务

每轮会随机选出行动玩家：

- 4 人及以下时，选出 1 名行动玩家
- 5 至 8 人时，选出 2 名行动玩家

行动玩家需要选择任务方向，并前往指定地点亲自完成挑战。任务内容会向所有玩家公布，其他玩家也可以关注行动过程。

如果没有在倒计时结束前完成选择，该玩家本轮不会获得任务收益。

## 信息与权重

- 你可以在屏幕上查看自己的四项属性。
- 每轮结束后，只会公布每项属性当前领先的玩家，不会公开所有人的完整数值。
- 某些轮次结束后会发生随机事件，改变四项属性在最终计票中的权重。
- 当前领先并不代表一定获胜。根据权重变化及时调整策略，才是赢得竞选的关键。

## 游戏流程

1. 在大厅阅读教程并选择候选人身份。
2. 游戏开始后进入自己的竞选办公室。
3. 每轮根据身份分配，完成决策任务或行动任务。
4. 关注属性领先者和随机事件带来的权重变化。
5. 最后一轮结束后，所有玩家前往市政厅参加最终计票。
6. 总票数最高的候选人当选市长。

## 竞选提示

- 不要只追求单项属性，权重变化可能让原本不起眼的属性成为胜负关键。
- 激进方案往往收益更高，但也可能损害其他方面。
- 注意其他玩家的领先项目，推测他们的竞选路线。
- 留意屏幕标题、聊天提示和倒计时，及时完成选择。
- 没有永远正确的政策，真正重要的是在当下局势中作出取舍。

祝各位候选人竞选顺利！
