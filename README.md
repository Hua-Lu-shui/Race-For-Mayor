## 📖 项目简介

《我要当市长》是一款最多支持 **8 名玩家** 的多人竞选游戏。每位玩家都将扮演一名市长候选人，在独立的竞选办公室中处理城市议题、参与实地行动，并经营自己的四项核心属性。

游戏不会直接告诉你每个方案造成的具体变化。你需要根据事件背景判断政策影响，在短期收益、长期发展与竞选形象之间作出取舍。

> 这不是一道寻找标准答案的题，而是一场关于判断、风险和时机的竞选。

## ✨ 核心特色

- 🎭 **5 种候选人身份**：不同身份拥有独特的初始属性与发展优势
- 🏙️ **4 项城市属性**：名誉、经济、民生与生态共同决定竞选表现
- 🗳️ **60 个决策事件**：覆盖舆论、产业、公共服务和环境治理等议题
- 🚶 **20 个行动任务方向**：行动玩家需要前往现场完成公开挑战
- ⏱️ **限时决策机制**：玩家需要在 30 秒内选择任务与政策方案
- 🔒 **隐藏信息博弈**：政策方案不会提前展示具体属性变化
- 🎲 **随机任务与房间**：玩家顺序、办公室和每轮任务均具有随机性
- ⚖️ **属性下限保护**：四项属性最低为 0，不会出现负数

## 📊 四项核心属性

| 属性 | 代表内容 | 战略意义 |
| :---: | --- | --- |
| 🩵 **名誉** | 公众形象、媒体评价、竞选声望 | 提升候选人的社会影响力 |
| 🟡 **经济** | 财政状况、商业活力、就业与发展 | 为城市建设提供持续动力 |
| 🔴 **民生** | 公共服务、住房、教育与生活保障 | 反映市民的生活质量与满意度 |
| 🟢 **生态** | 环境质量、污染治理与城市宜居度 | 决定城市的可持续发展水平 |

所有属性最低为 `0`。激进政策可能带来更高收益，但也可能牺牲其他领域。

## 🎮 游戏流程

```text
候选人大厅
   ↓
阅读教程并选择身份
   ↓
随机分配竞选办公室
   ↓
进入回合：决策任务 / 行动任务
   ↓
在限定时间内选择方向与方案
   ↓
结算属性变化并进入下一轮
   ↓
最终计票，选出新任市长
```

### 决策任务

普通玩家会收到一项城市议题：

1. 从随机出现的三个属性方向中选择一个。
2. 阅读对应事件的背景与矛盾。
3. 在三种政策方案中作出决定。
4. 承担选择带来的收益与代价。

方案只展示政策内容，不会提前公开具体数值变化。

### 行动任务

每轮会随机选出行动玩家：

- `1～4 人`：随机选出 1 名行动玩家
- `5～8 人`：随机选出 2 名行动玩家

行动玩家需要选择任务方向并前往指定地点完成挑战。行动内容会向全体玩家公布，其他候选人可以观察其表现。

> 如果玩家没有在倒计时结束前完成选择，本轮不会获得对应任务收益。

## 🧠 竞选策略

- 不要只发展单项属性，过度偏科会降低应对变化的能力。
- 高收益方案通常伴随着更明显的代价。
- 根据事件背景判断后果，而不是只凭方案措辞选择。
- 留意其他玩家的领先方向，推测他们的竞选路线。
- 关注标题、聊天消息和倒计时，避免错过本轮选择。

## 📦 安装与使用

### 环境要求

- Minecraft Java Edition `1.21.1`
- 数据包格式 `48`
- 推荐玩家数量 `1～8 人`
- 游戏中需要允许执行命令

### 安装方法

1. 打开目标世界文件夹。
2. 进入该世界的 `datapacks` 目录。
3. 将整个 `Race For Mayor` 文件夹放入其中。
4. 进入世界后执行：

```mcfunction
/reload
```

看到“加载完毕”后，数据包即已成功载入。正常游玩时，可在大厅点击发光告示牌查看教程、选择身份并开始游戏。

### 调试命令

如需跳过大厅告示牌直接检查开始流程，可使用：

```mcfunction
/function rfm:schedule/start_check
```

## 🤝 参与开发

如果你希望添加新的城市事件，可以在对应属性目录下按照现有结构创建：

```text
事件名_show.mcfunction    # 展示背景与三个政策方案
事件名_a.mcfunction       # 方案 A 的结果
事件名_b.mcfunction       # 方案 B 的结果
事件名_c.mcfunction       # 方案 C 的结果
```

提交修改前，请确保：

- `*_show.mcfunction` 只展示背景与政策内容，不提前泄露数值结果。
- 每个方案最多影响三项属性。
- 收益更高的方案应当具备相应风险或代价。
- 超时玩家不会被强制执行默认方案。
